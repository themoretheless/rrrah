For each rounded coordinate interval, enumerate all intersected LUT segments, including knots. The original diff=upper-value is enclosed directly and constrained to[0,1]. The exact curve with that same diff is tu+(tl-tu)*diff; its interval uses diff once. The original separate/fused mul-add path is enclosed by adding8*u*M+8*eta where u=f32 EPSILON (twice unit roundoff), M=max(abs(tu),abs(tl)), eta=min positive f32 subnormal. This conservatively covers both products, subtraction and final addition, including gradual underflow; interval evaluation also encloses the exact shared-diff expression. Segment results are unioned. Input curve ranges are clamped as the actual hybrid fetch does, then passed through the CLUT interval core and output curves. This stops at encoded profile PCS and does not include PCS/RGB/display stages.
