The bound uses the same immutable transform executor as point conversion. Supported initial-stage bounds enclose input curves/CLUT/output curves. Each matrix row preserves original coefficients and separate/fused multiply-add order via outward intervals. Lab→XYZ applies encoded L/a/b scaling, inverse-Lab linear and cubic branches (union if crossed), the original D50 white point and exact f64 normalization constant, then outward f32 endpoint conversion. Final RGB conversion bounds rounded gamma lookup indices and reads every reachable immutable table entry; no monotonic-table assumption. RGB-layout alpha finalizers are admitted only when their actual implementation leaves RGB entries unchanged. Unsupported stages refuse. This stops at bare float RGB, not premultiplied alpha/display pixels.
