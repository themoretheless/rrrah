# EPS rectfill device-pixel semantics and concat gate

Numeric rectfill now records distinct RectFill provenance instead of becoming indistinguishable from ordinary fill. When the final five-edge shape and every active clip are explicitly closed axis-aligned rectangles, rasterization resolves their continuous bounds first and selects touched device pixels. Zero width paints one device column; zero height selects the preceding device row. Extent selection occurs before page clipping, so an off-page zero rectangle does not become an in-page pixel. Disjoint clips and point-only clip intersections remain empty; shared-edge intersections of nonempty clips follow the independently observed device-strip rule. Ordinary collinear fill stays empty. Nonrectangular/open clip representations and non-axis-aligned transformed rectangles retain the existing geometric coverage path; this is not universal Ghostscript scan-conversion parity.

The rule is supported by independent authored references and comparison with the reference device behavior in https://github.com/ArtifexSoftware/ghostpdl/blob/gs10.05.1/base/gsdps1.c . Native Rust uses its own admitted scene/mask pipeline. No arbitrary geometry epsilon, external production renderer, reference pixel patch or filtered failing case is introduced.

Eleven independent Ghostscript10.05.1 cases cover vertical/horizontal/point zero extents, a fractional small rectangle, off-page geometry, interior and boundary clipping, shared-edge/gap/point clip intersections and ordinary collinear fill. Reproduce with generate-eps-pixel-ghostscript-reference.py --device-rects. Together with the six unchanged matrix cases, every selected native pixel, restored SDR frame and binary16 HDR frame passes the common decode/RAMeviction/swap/fullpressure/cancellation/retry lifecycle. Former singular_fill strict gate is now green. All13EPS lifecycle tests pass with0ignored on MetalM4Max; all116selected oracle cases remain in the suite, retaining previous explicit gray-midpoint and ellipse exclusions.

A new raster regression interrupts every callback in the successful reference path and probes every output budget below its measured working peak; each refusal releases credit and any admitted output remains exact. Retry and source/output teardown return root credit tozero. Device geometry replaces its flat buffer rather than overlapping another retained copy. A prior general-fill clip mask is discarded before device coverage allocation, and the existing tight-cache-eviction regression remains meaningful by explicitly seeding a general path mask.

Old rectangle/path-equivalence assertions now distinguish the independently confirmed zero-point rectfill from a zero-area ordinary path. Intermediate failures (lost primitive kind, boundary clipping and clip-cache assumptions) remain in raw logs. Broader EPS, generic fractional/diagonal/ellipse scan conversion, all100formats, liveGUI, calibrated physicalHDR and NVIDIA remain unqualified.
