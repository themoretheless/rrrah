# Production adaptive Tensor candidate: fidelity improvement, memory gate not met

The ordinary PDF renderer streams a fixed 722 triangles per Tensor patch; existing adaptive tessellation is separate. An experiment connected admitted adaptive geometry to the production sampler for visible one-to-four-component Tensor patches, preserving coincident-patch ordering, opacity, background and transfer state. Geometry is generated in device coordinates. Other mesh kinds and >4 components retain the original route. Candidate limits: geometry1/64 pixel, source components1/1024, depth12, at most1048576 triangles. These are source-component bounds, not ICC/output-color certificates.

Independent authored control: 32x64 solid-red Tensor patch with x=32u, y=2+8v+128u(1-u). Its alpha oracle is generated by exact piecewise polynomial antiderivatives over each pixel, splitting at the quadratic boundary roots. It does not call the renderer, tessellator or Poppler. Coordinate32 quantization is bounded below7.5e-9 page units. Generator, CC0 fixture, alpha bytes and metadata are retained.

Across all2048 pixels, fixed-grid output has maximum alpha error19, 104 pixels above error3, 164 nonexact pixels and summed error956. The compact adaptive candidate matches every alpha byte exactly. The source/reference output is still compared with the original criterion; no tolerance was relaxed. Raw authored RGBA outputs and hashes are adjacent.

Binary hashes are recorded separately by each Poppler report.

Memory rejects default integration:
- Generic admitted triangles made the existing planar-color test fail at its unchanged1MiB budget.
- Compact storage restores that1MiB test. A legacy admission assertion expecting722 triangles needs structural adaptation, not a larger budget.
- The new curved control still cannot complete with8MiB: an additional3285360-byte reservation is refused while5736013 bytes remain live. The next overlap would require9021373 bytes, before any later growth. This is an admission observation, not measured RSS or a claim that9021373 is the final peak.
- A finite huge-coordinate depth/refusal control also fails its intended precision-error assertion in the integrated candidate. The candidate therefore does not meet all acceptance gates.

Do not ship this switch or hide the failure by increasing cache budgets. Production encode/shading/render files were restored to their pre-experiment state; previous font correctness fixes remain. The candidate patch is preserved for research against7bd1a01b5 and includes earlier local font changes. The extreme authored control is research-only. Candidate source files are not active production changes.
