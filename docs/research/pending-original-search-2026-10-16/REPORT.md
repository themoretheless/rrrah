# Additional original-source search

The public `f-spot/raw-samples` repository describes samples for Taglib# tests. Its complete recursive Git tree was inspected through the GitHub API (snapshot and SHA stored alongside). Nine blobs, zero BAY/CAP/PTX/RWZ/MEF suffixes and zero Casio path matches. The lone RAW directory entry is Leica Digilux2. This eliminates one candidate source, not availability elsewhere.

Sources: https://github.com/f-spot/raw-samples and https://api.github.com/repos/f-spot/raw-samples/git/trees/master?recursive=1 . Existing Casio layout documentation https://www.inweb.ch/foto/rawformat.html still describes Bayer Capture and layout; no new camera-produced sample was obtained. Catalogue counts and native viewer acceptance remain unchanged.
