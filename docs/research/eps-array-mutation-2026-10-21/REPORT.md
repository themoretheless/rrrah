# Native EPS allocated arrays and put

Added array(length) allocation with null-filled entries and indexed put mutation using the existing first-use admitted flat arena. The full arena remains bounded by max_operands including one sentinel per object; cumulative storage never grows beyond that capacity. Literal and allocated arrays now share the same checked range/admission helper. Put validates target/index and polls work/cancellation before mutation; it does not allocate or resize storage.

Aliases reference the same stable arena range, so a put through one alias is visible through another. Nested and self-referential arrays use numeric handles rather than owning references: the arena can contain its own handle without forming an Arc ownership cycle. Last evaluation-clone drop frees all managed storage. Tests cover null initialization, aliases, nested values, cyclic identity, negative lengths/indices, invalid target types and bounds. Every cancellation checkpoint in the successful self-cycle program is replayed and must return Cancelled with original root usage; same-root retry succeeds and final ownership is0.

Independent Ghostscript10.05.1 scalar control matches null/length/read/write/alias/nested/cyclic-equality results. Four independently generated8x8pixel cases cover allocated matrix construction, aliased matrix update, nested mutable color and cyclic identity controlling color. They pass public decode/RAMcount eviction/swap pressure/cancellation/retry and exact32x32SDR/binary16HDR Metal output, finalroot0.
