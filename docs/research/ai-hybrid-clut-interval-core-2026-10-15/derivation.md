Each operation encloses both its exact real result and rounded f32 result with adjacent outward endpoints. Products inspect all four endpoint pairs; sums/subtractions use ordered endpoints. Coordinate boxes must share a CLUT cell. All six M/Y/K permutations that cannot be excluded by interval ordering are evaluated and unioned; this includes stable tie ordering and every branch feasible anywhere in the box. For each ordering both C slices and all four tetrahedral vertices use the original indexed CLUT values and operation order. Fused arithmetic is also enclosed because intermediate intervals contain the exact real intermediates. This bounds the hybrid CLUT only, assuming gradual underflow; it does not bound surrounding curve or PCS stages.
