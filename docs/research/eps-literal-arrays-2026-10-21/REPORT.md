# Native bounded EPS literal arrays

Literal brackets now evaluate element code and construct arrays in a managed fixed-capacity arena. Nested arrays and procedures are stored as copyable handles; length and indexed get are supported. Each array consumes its element slots plus one internal accounting/identity sentinel; the separate cumulative arena capacity equals EpsVmLimits.max_operands. Capacity is admitted once on the first actual construction, never grown incrementally. Scalar programs therefore retain their prior tracked payload cost. The returned evaluation owns the arena through its last clone, including handles nested in returned arrays.

Searching for the closing mark and copying elements charge work/cancellation. Unmatched close, invalid index and cumulative arena exhaustion refuse without publishing evaluation; temporary managed credit returns to the pre-execution baseline. Tests cover cancellation after ordinary VM admission and after the array arena itself is admitted, same-root successful retry and finalzero ownership. Empty arrays compare equal, including empty procedures, matching the independent interpreter; separate nonempty arrays retain distinct identity and aliases compare equal.

Ghostscript10.05.1 independent scalar output matches computed elements, nested indexing, alias/empty identity, length and for-generated elements. Separate empty-array/procedure and nonempty-array comparisons match. Both raw oracle logs are retained. Two intermediate failures are retained: an old test still expected [] to refuse, then an eager arena doubled scalar retained payload. Final implementation replaces the stale unsupported-input case with unmatched ] and uses first-use arena admission, preserving the original scalar accounting assertion.
