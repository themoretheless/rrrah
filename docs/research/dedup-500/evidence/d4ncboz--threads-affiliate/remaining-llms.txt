# Threads Affiliate Poster ID

> Open-source toolkit for automated Indonesian-language affiliate posting to Threads (Meta) with anti-spam rotation, dedup logic, and clean affiliate link insertion. Powered by Python + Playwright + cookie-based authentication.

This project enables affiliate marketers (primarily Shopee Indonesia) to automate 2-3 post chains on Threads, with built-in anti-spam features: category rotation, hook similarity detection, link reuse prevention, and human-like typing patterns.

## Key Concepts

- **3-post chain format**: Native Threads feature that boosts engagement. Hook (post 1) → Review body (post 2) → CTA with affiliate link (post 3).
- **Hook styles** (9): edukasi, validasi_mental, storytelling, problem_solving, hook_pancingan, transformasi, social_proof, urgency, controversy.
- **Categories** (4): skincare, parfum, haircare, makeup.
- **Cookie-based auth**: Uses session cookies from a logged-in Chrome browser (Instagram + Threads via Meta SSO). No password/2FA flow.
- **Markdown database**: Affiliate links tracked in human-editable `.md` table.
