# 01 — Account Setup

This step is **manual** (human-only). It must be done before any automation can run.

## Part A: Threads (Meta) Account

Threads is part of Meta's ecosystem and uses Instagram credentials via SSO (Single Sign-On).

### 1. Create Instagram Account

| Step | Action |
|------|--------|
| 1.1  | Download Instagram app (iOS/Android) or visit [instagram.com](https://instagram.com) |
| 1.2  | Sign up with **real email** and **real phone number** (must be verifiable) |
| 1.3  | Choose a brandable username (short, niche-relevant, e.g. `bagus.skincare.id`) |
| 1.4  | Upload a real-looking profile photo (avoid stock images) |
| 1.5  | Write a clear bio mentioning your niche + affiliate disclosure |
| 1.6  | Verify email + phone number |
| 1.7  | Follow 50-100 accounts in your niche (warms up the algorithm) |
| 1.8  | Post 3-5 manual photos/reels in your niche before automation |

### 2. Activate Threads Profile

| Step | Action |
|------|--------|
| 2.1  | Go to [threads.com](https://www.threads.com) |
| 2.2  | Click "Continue with Instagram" |
| 2.3  | Meta SSO auto-creates Threads profile linked to your IG |
| 2.4  | Confirm Threads username (default: same as IG) |
| 2.5  | Set Threads bio (can differ from IG) |
| 2.6  | Post 3-5 manual threads to warm up the account |

### ⚠️ Critical: Warm-Up Period

**Do NOT start automation immediately after signup.** Threads' spam detection is aggressive on new accounts.

| Account Age | Max Daily Posts via Automation |
|-------------|-------------------------------|
| 0-2 days    | 0 (manual posts only)          |
| 3-7 days    | 1 post/day                     |
| 1-2 weeks   | 2 posts/day                    |
| 2-4 weeks   | 3 posts/day                    |
| 1+ month    | Recommended max 3 posts/day    |

## Part B: Shopee Affiliate Registration

Shopee Affiliate Program (SAP) is Indonesia's most accessible affiliate program.

### Prerequisites

- Valid Indonesian KTP (national ID)
- Active Shopee buyer account (sign up at shopee.co.id if needed)
- Bank account for commission payout (BCA/Mandiri/BRI/BNI common)
- Optional: NPWP (tax number) — not required but increases trust

### Registration Steps

| Step | Action |
|------|--------|
| B.1  | Visit [affiliate.shopee.co.id](https://affiliate.shopee.co.id) |
| B.2  | Click "Daftar Sekarang" (Register Now) |
| B.3  | Sign in with existing Shopee account |
| B.4  | Fill profile: name (per KTP), date of birth, gender |
| B.5  | Upload KTP photo (front side, clear, no glare) |
| B.6  | Verify KTP via selfie + KTP (in-app camera) |
| B.7  | Set Profile Description — mention your niche (skincare reviewer, fashion blogger, etc.) |
| B.8  | Add bank account for payout |
| B.9  | Add main social platforms (Instagram, TikTok, Threads) |
| B.10 | Submit application |
| B.11 | Wait approval (24-48 hours typically) |

### After Approval

You will receive:
- **Affiliate dashboard access** — track clicks, conversions, commission
- **Link Generator tool** — convert any product URL to `s.shopee.co.id/XXXXX` short link
- **Performance reports** — daily/weekly/monthly stats
- **Commission tiers** based on niche (typical 3-15%)

### Commission Reference (as of 2026)

### Cookie Window
Buyer must purchase within **7 days** of clicking your affiliate link for you to earn commission.

## Part C: Generate Your First Affiliate Link

| Step | Action |
|------|--------|
| C.1  | Open Shopee app or shopee.co.id, find a product |
| C.2  | Copy product page URL |
| C.3  | Open Affiliate Dashboard → "Buat Link" (Create Link) |
| C.4  | Paste URL, optionally add UTM tag for tracking |
| C.5  | Click "Generate" — you get `s.shopee.co.id/XXXXX` |
| C.6  | Save this link to your **affiliate database** (next doc) |
