# Pro/editor roadmap: F101–F200

Это расширение карты [F01–F100](EDITOR_100.md). Функции ниже являются
контрактом проектирования: каждая имеет явные зависимости, вычислительный путь,
бюджет памяти, benchmark gate и критический риск. Preview и quality-path должны
оставаться разными профилями качества.

Обозначения: `CPU` — SIMD/parallel CPU, `GPU` — wgpu compute/render, `ML` —
опциональная модель, `IO` — bounded storage/network. Формула memory в строках
относится к активному tile, если не указано иное.

## Общий benchmark contract

Каждая функция запускается на cold/warm cache и на 1/2/4/8/16 workers.
Сохраняются p50/p95/p99, bootstrap 95% CI, MAD outliers, peak RSS/VRAM,
cycles/px, GB/s, GPU kernel/upload time и frame deadline misses. Базовые формулы:

```text
speedup(P)   = T(1) / T(P)
efficiency   = speedup(P) / P
first_frame  = probe + visible_decode + postprocess + upload + present
roofline     = max(bytes / bandwidth, FLOPs / peak_FLOPs) + sync_cost
```

Release gates: p95 latency +10%, RSS/VRAM +10%, cache hit ratio −5 percentage
points, ΔE00 p95 +0.2, tile seam >1 LSB или checksum mismatch — regression.
ML-функции обязаны иметь deterministic CPU oracle, human-review toggle и
метрику hallucination; native/WASM plugins проходят capability negotiation,
memory/time limits и signed-golden-corpus tests.
